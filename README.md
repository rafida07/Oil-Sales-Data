# Mini-Project oil Sales Dashboard

Project Overview

This project is an interactive Oil Sales Dashboard developed using Power BI. The dashboard helps analyze sales performance, product trends, customer behavior, and business insights through various visualizations.

Tools Used

* Power BI
* Microsoft Excel
* Power Query
* DAX

Dataset Information

The dataset contains oil sales records including:

* Product Name
* Category
* Sales Amount
* Quantity Sold
* Customer Details
* Location Information
* Order Details

Dashboard Features

* Total Sales Analysis
* Product-wise Sales Performance
* Category-wise Comparison
* Sales Trend Analysis
* Regional Sales Distribution
* Interactive Filters and Slicers
* Business Insights and Recommendations

Key Insights

* Identified top-performing products.
* Compared category-wise sales performance.
* Analyzed sales trends across different regions.
* Generated business recommendations based on sales patterns.oject
